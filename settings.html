Tentang Prototipe BudgetPas Pure Web App

Website ini dirancang khusus sebagai prototipe aplikasi pengelolaan keuangan mahasiswa yang dibangun secara Pure Web Application menggunakan HTML5, CSS3, dan Vanilla JavaScript (ES6) dengan arsitektur Multi-Page Application. Setiap tampilan dipecah menjadi file HTML terpisah yang terhubung secara rapi melalui navigasi browser dan berbagi data secara tersinkronisasi lewat LocalStorage & Data Dummy JSON.
